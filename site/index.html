架构总览

任务状态机

PENDING → RUNNING → SUCCESS / FAILED / CANCELLED，RUNNING ⇄ PAUSED。
迁移校验、迁移历史、全生命周期事件。

tasks/statemachine.js

流水线执行器

阶段链式传递、失败即停（带阶段名）、断点续跑（跳过阶段向下游传 null）、阶段级事件。

workflows/pipeline.js

领域模型

Question 十态生命周期（DISCOVERED → … → SUBMITTED），fingerprint 去重（URL pathname + 标题哈希），旧数据零破坏升级。

domain/question.js

LLM 分层

Provider（OpenAI 兼容传输）+ Strategy（提问模板/清洗）+ Client（并发闸/退避重试/token 记账/日预算）。

llm/*

质量门

长度/格式/AI 痕迹/标题复读/相关性/重复度 七项检查 → 评分 → PASS / REVIEW 决策。

quality/gate.js

可观测性

事件总线（精确/前缀/全量订阅）→ 运行日志（账号打码）+ 审计日志（JSONL 按天）+ 健康自检流水线（8 阶段）。

在线演示（模拟环境）

以下演示运行在本地模拟站上——它与真实页面的 DOM 结构对齐，但完全离线、不访问任何真实平台、不产生真实发布。用于展示任务引擎与流水线的真实行为。

① 爬题流水线

进入答题区 → 锁定分类 → 逐题打开 → 提取标题与链接 → 指纹去重 → 入库。

② AI 生成 + 质量门

LLM 生成回答 → 质量门七项检查 → 评分 → PASS / REVIEW 决策。

③ 健康自检

8 阶段自检流水线：模拟站 → 浏览器 → 引擎装配 → 爬题 → 生成 → 提交 → 核对 → 通过数。

演示需要本机启动演示后端（node site/server.js），数据仅存在于内存。
