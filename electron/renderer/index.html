一键全自动

⚠️ 这条链会自动爬题、生成答案、提交到平台、并按题材上传。全程无人值守，中途出错只会写进运行日志。请务必先取消勾选「自动提交」「网盘转存」「按题材上传」，小批量试跑一次，确认链路通了再放开。

跑之前请先在「比特环境」页配好：账号列表、账号题材绑定、上传分类规则；并在「生成答案」页填好 AI Key。

两个阶段串起来看：答题链 爬题→抽题→AI 生成→提交（积累通过数）；网盘链 转存（脚本套模板生成问答）→按题材拆表→分账号上传。两条链可单独勾选。

网盘链没指定资源表时，会先按账号绑定的题材自动搜资源（纯协议，不需要浏览器），搜到的结果直接喂给转存。

上传完成后会自动核对收录——上传接口返回成功只代表平台收下了，平台还要异步审核，所以这一步单独查「收录了多少 / 被拒多少」。

只想让一部分账号参与时在这里填。搜资源也会只按这些账号绑定的题材去搜。

负责把资源转存进自己网盘并建好分享链接 —— 所以这些号需要有网盘空间（不需要批量发布权益）。

负责把问答表传到百度知道工作台 —— 所以这些号需要有批量发布权益（不占它的网盘）。两边填不同的号，就能「A 转存、B 上传」：链接是公开的，谁上传都行。

只管逐题提交那条链（自己设的风控护栏，与平台额度无关）。网盘上传不受它约束。

批量上传（星链知道批量发布）

把「批量转存」生成的上传专用表分批上传到百度知道答主工作台。自动读取剩余额度、随机排序防查重，失败即停可重跑续传。

「查收录」为什么必要：上传接口返回成功只代表平台收下了，之后平台还要异步审核。 「上传成功」≠「被收录」——上传完点一下这个，会按账号列出最近的上传记录（收录多少条 / 被拒多少条），并导出明细表。

「按题材分账号上传」会按设置页的分类规则给每行派生题材，拆成一个题材一张表（存到源表同级的「分表」目录，可人工过目），再把每张表交给绑定了同名题材的账号上传（账号在设置页「账号题材绑定」里配）。没命中规则的行不会进任何分表，本次不上传。

使用教程

🔧 比特浏览器环境配置（每个账号一个环境）

  1. 在比特浏览器里新建环境，名称建议直接用账号名（如 测试组1、测试组2）。 软件「比特环境」页里填的环境名必须和这里一字不差，差一个字就找不到窗口。
  2. 必须在这个环境里登录百度账号——这是最容易漏、也最容易被误判成"配置坏了"的一步。 打开环境 → 访问 zhidao.baidu.com → 右上角登录。 登录成功后这个环境的 Cookie 里才会有 BDUSS；没登录的环境虽然也能打开百度知道首页， 但答题入口、活动页、工作台都会失效。
    转存网盘还要再登录一次 pan.baidu.com（同一账号，登录后 BDUSS 和 STOKEN 都会带上）， 否则转存时会提示"该账号无网盘登录态"并跳过。
  3. 代理留空即可（直连）。若要用代理，务必确认它能访问百度——代理不通的表现同样是"页面打不开"， 容易和别的毛病混在一起。
  4. 回到软件「比特环境」页，把环境名填进「比特环境名称」（每行一个），点测试连接确认能连上比特 API。

❓ 环境像"打不开百度知道"——先看这三条

  1. 百度知道是客户端渲染的，页面要等十几秒才出内容。 刚打开时是空白壳：实测同一个问题页 2 秒时只有 4.6KB，12 秒后才渲染出完整内容（1.38MB）。 等一会儿再看，那不是打不开。
  2. 没登录就没有答题入口。未登录环境打开百度知道首页是正常的， 所以光看首页会误以为没问题；真正需要账号的地方（活动页 / 工作台）才会失效。 判断办法：和环境里的 Cookie 对比——登录过的环境 zhidao.baidu.com 下一定有 BDUSS。
  3. 转存提示"该账号无网盘登录态"，是 pan.baidu.com 没登录，不是环境坏了。 软件会自动跳过该账号并把原因写进运行日志。

⭐ 换电脑 / 重装后防重复答题（重要）

  1. 软件的答题历史（答过哪些题、抽题进度、题库）存在数据目录，不在软件文件夹里：按 Win+R 输入 %APPDATA%\zhidao-answer-studio 回车即可打开。
  2. 换电脑/重装前，把该文件夹整体拷贝到新电脑的同一位置（%APPDATA%\zhidao-answer-studio），再安装/解压新软件——历史答题记录全部恢复，抽题不会重复。
  3. 不拷贝的话，新电脑会当作全新开始：重新爬题爬回来的还是活动页那批题，答过的会被再次抽中（软件会在抽题时尽量排除已提交/已生成过的，但前提是数据目录里有历史）。
  4. 更新软件版本时不需要动数据目录：安装新版或替换软件文件夹即可，答题历史始终保留。

① 准备工作（一次性）

  1. 安装比特浏览器（bitbrowser.cn）并注册登录；打开「系统设置 → 本地设置」→ 开启 API 服务（默认端口 54345，无需改动）。
  2. 在比特浏览器「浏览器窗口」页新建窗口：一个百度账号建一个窗口，窗口名建议用「账号1」「账号2」。
  3. 双击窗口打开 → 在里面登录你的百度账号（推荐扫码，最不容易触发验证）。登录一次即长期有效。
  4. 回到本软件 → 「比特环境」页 → 环境名称每行填一个窗口名 → 点「测试连接」看到 ✅。

② 爬取题目（免费，积累题库）

  1. 「题目爬取」页 → 选好分类 → 点「开始爬取」。程序会自动进入活动页、逐题记录标题和链接。
  2. 爬取支持断点续爬：中途停止后勾选「断点续爬」即可从上次位置继续；已入库的题自动跳过。
  3. 「题库浏览」页可随时搜索、翻看已爬取的题目。

③ 生成 AI 回答（需硅基流动 API Key）

  1. 注册 cloud.siliconflow.cn 并创建 API Key，在「生成答案」页填入保存。
  2. 「随机抽题」页 → 设数量 → 「随机生成表格」产出一个 xlsx。
  3. 「生成答案」页 → 来源表格会自动填好 → 点「开始生成」。生成结果自动写回表格并带「质检」列。
  4. 质检为 REVIEW 的行建议人工修改后再提交；PASS 的可直接用。

④ 提交回答（两种方式）

方式 A · 批量通道（推荐，官方支持）：工作台筛题下载表格 → 用本软件生成回答填入「回答内容」列 → 工作台上传表格，平台批量审核。额度随有效回答数解锁（10 条→1000，30 条→5000，60 条→10000）。

方式 B · 自动提交：「自动提交」页选同一张表格 → 设「每账号每日限额」（建议 ≤10）→ 开始。系统自动轮换账号、跳过已提交、检测账号是否已达标。

⑤ 每日循环（一键脚本）

在项目目录打开命令行：node scripts/daily-batch.js 10 = 抽新题 → AI 生成 → 自动提交 10 条，一条命令完成当日任务。

⚠️ 安全红线（务必遵守）

  1. 新账号首周每日提交 ≤ 5 条，账号稳定后再逐步放到 10~30 条。
  2. 保持「操作间隔」默认值（8~20 秒随机），千万不要调小——0 延迟会触发平台风控导致会话失效。
  3. 遇到「安全验证」立即停下手动处理，绝不要让程序连续重试。
  4. 一键自检（比特环境页按钮）可随时验证整条链路，不消耗账号额度。
